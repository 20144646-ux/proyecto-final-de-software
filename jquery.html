jQuery

Una biblioteca de JavaScript que facilita tareas comunes en páginas web.

¿Qué es jQuery?

jQuery es una biblioteca de JavaScript que simplifica la selección de elementos HTML, el manejo de eventos, las animaciones y algunas solicitudes de datos.

¿Para qué sirve?

  • Detectar clics en botones.
  • Cambiar textos y estilos de elementos.
  • Mostrar u ocultar contenido.
  • Crear efectos y animaciones sencillas.

Ejemplo interactivo

Este texto cambiará cuando presionés el botón.

$("#cambiarTexto").on("click", function () {
  $("#textoDemo").text("¡El texto ha cambiado!");
});
