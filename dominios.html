Dominios web

La dirección que permite encontrar un sitio en Internet.

¿Qué es un dominio?

Un dominio es el nombre que las personas escriben en el navegador para acceder a un sitio web, como ejemplo.com. Se utiliza porque es más fácil recordar un nombre que una dirección IP numérica.

Partes de un dominio

Por ejemplo, en www.voltix.com:

  • www: es un subdominio de uso común, pero no obligatorio.
  • voltix: es el nombre elegido para el dominio.
  • .com: es la extensión o dominio de nivel superior.

Tipos de extensiones

  • .com: utilizada ampliamente por empresas y proyectos comerciales.
  • .org: común en organizaciones.
  • .edu: relacionada con instituciones educativas en ciertos sistemas de registro.
  • .sv: extensión territorial de El Salvador.
  • .net: utilizada por diferentes tipos de proyectos y servicios.

¿Dominio y hosting son lo mismo?

No. El dominio es la dirección del sitio y el hosting es el servicio donde se almacenan sus archivos. Para publicar un sitio con un dominio propio, normalmente se configura el dominio para que dirija al servicio de alojamiento.
