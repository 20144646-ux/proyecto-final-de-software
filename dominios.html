Nombres de Dominio

La dirección que identifica un sitio web en Internet.

¿Qué es un dominio?

Un dominio es el nombre único que utilizan los usuarios para encontrar un sitio web en Internet. Por ejemplo: google.com o wikipedia.org.

Partes de un dominio

www. nexusx .com

www

Es un subdominio tradicional utilizado para acceder a sitios web.

NEXUS X

Es el nombre elegido para identificar nuestra marca.

.com
