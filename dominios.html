Dominios

El nombre que las personas utilizan para entrar a un sitio web.

¿Qué es un dominio?

Un dominio es la dirección o nombre que identifica un sitio web en Internet. En lugar de escribir una dirección numérica complicada, podemos utilizar un nombre fácil de recordar.

Ejemplo

www.nexusx.com
www

Indica el servicio web.

nexusx

Es el nombre elegido.

.com

Es la extensión del dominio.
