JSON

Un formato sencillo para organizar e intercambiar información.

¿Qué es JSON?

JSON significa JavaScript Object Notation. Es un formato de texto que permite representar datos mediante objetos y listas. Se utiliza mucho para intercambiar información entre aplicaciones.

¿Cómo se organiza?

Los datos se escriben usando pares de claves y valores. Las claves y los textos van entre comillas dobles.

{
  "nombre": "Laptop",
  "precio": 549.99,
  "disponible": true
}

¿Para qué se utiliza?

  • Guardar información de productos.
  • Intercambiar datos entre sistemas.
  • Organizar configuraciones de aplicaciones.
  • Enviar y recibir información desde servicios web.

Ejemplo en VOLTIX

El archivo datos.json contiene los productos, sus descripciones, precios e imágenes. JavaScript lee esos datos para mostrarlos en el catálogo.
