Web Hosting

El servicio que permite publicar una página web en Internet.

¿Qué es el Web Hosting?

El Web Hosting, también llamado alojamiento web, es un servicio que guarda los archivos de un sitio web en un servidor conectado a Internet. Gracias a esto, otras personas pueden visitar la página desde sus dispositivos.

¿Para qué sirve?

  • Almacenar archivos HTML, CSS y JavaScript.
  • Publicar páginas web para que otras personas puedan visitarlas.
  • Mantener disponibles los recursos de un sitio.
  • En algunos planes, utilizar bases de datos y correo electrónico.

Tipos de alojamiento

Hosting compartido

Varios sitios utilizan recursos de un mismo servidor. Suele ser una opción económica para páginas pequeñas.

Servidor virtual privado (VPS)

Ofrece recursos virtuales separados y más control sobre la configuración.

Hosting en la nube

Utiliza infraestructura de varios servidores para alojar aplicaciones y sitios web.

Hosting dedicado

Un servidor físico se destina a un solo cliente, normalmente con mayor control y costo.

Ejemplos de plataformas

Estas son algunas plataformas que ofrecen servicios de alojamiento o publicación web:

  • GitHub Pages: publica sitios estáticos.
  • Vercel: facilita publicar sitios y aplicaciones web.
  • Netlify: permite desplegar proyectos web.

¿Cómo se relaciona con VOLTIX?

Actualmente, VOLTIX se ejecuta localmente en el equipo mediante VS Code y Live Server. Para que otras personas puedan visitarlo por Internet, habría que publicarlo en un servicio de hosting.
